# MySphere Website

Marketing site for MySphere: companionship for adults 55+, matched by Sonia, a multilingual voice assistant.

Static HTML/CSS/JS with no build step. Open `index.html` or host anywhere (GitHub Pages, Netlify, Vercel).

## Pages
- `index.html`: hero, problem (sourced stats), how it works, Sonia, who it's for, CTAs

## Design
- Type: Instrument Serif (display), Geist (body), Geist Mono (labels), all from Google Fonts
- Color tokens live at the top of `styles.css` (`--paper`, `--ink`, `--rose`, `--butter`)
- App screenshots in `images/app-screen-*.png` have a pink canvas baked in; `.shot-1/2/3` in `styles.css` clip them to the phone frame. If you replace a screenshot, retune its `clip-path` inset.

## Forms
- Waitlist and companion links point to Google Forms; search for `docs.google.com` to update them.
